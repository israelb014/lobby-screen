# מסך לובי — בניין המגורים ברמלה

מסך מידע ללובי (1920×1080). הוא רץ 24/7 בדפדפן Chromium במצב קיוסק ומתעדכן לבד.

**כתובת המסך:** https://israelb014.github.io/lobby-screen/

בדיקה ותצוגה מקדימה:
- `?preview=1` — מוסיף בפינה השמאלית העליונה כפתורים: יום / לילה / שבת.
- `?now=2026-11-13T17:00` — מדמה תאריך ושעה (שעון ישראל). אפשר לשלב: `?preview=1&now=2026-11-13T17:00`.

## יצירת הגיליון ב-Google Sheets

### 1. יצירת הגיליון
1. היכנס ל-https://sheets.google.com ולחץ על **ריק** (גיליון חדש).
2. למעלה משמאל לחץ על "גיליון אלקטרוני ללא שם" ותן לו שם, למשל `מסך לובי`.

### 2. לשונית "הודעות"
1. למטה, לחץ פעמיים על שם הלשונית `גיליון1`, כתוב `הודעות` ולחץ Enter.
2. בשורה 1 כתוב את הכותרות, כל אחת בתא נפרד:

   | A | B | C | D |
   |---|---|---|---|
   | פעיל | קטגוריה | כותרת | תוכן |

3. מהשורה 2 והלאה, כל שורה היא הודעה. לדוגמה:

   | פעיל | קטגוריה | כותרת | תוכן |
   |---|---|---|---|
   | כן | הודעת ועד הבית | נא הקפידו לסגור את דלת הכניסה | נא הקפידו לסגור את דלת הכניסה לבניין... |
   | לא | תחזוקה וניקיון | ניקיון חדר מדרגות | ביום ראשון בשעה 09:00... |

   - **פעיל**: `כן` = ההודעה מוצגת. `לא` = ההודעה מוסתרת (בלי למחוק אותה).
   - **קטגוריה**: מוצגת כתגית זהב קטנה מעל הכותרת.
   - אפשר לרדת שורה בתוך תא עם Ctrl+Enter.

### 3. לשונית "תמונות"
1. למטה משמאל לחץ על **+** (הוספת גיליון). לחץ פעמיים על שם הלשונית החדשה וכתוב `תמונות`.
2. בשורה 1:

   | A | B |
   |---|---|
   | פעיל | תמונה |

3. מהשורה 2 והלאה, כל שורה היא תמונה בתמונה הגדולה של הבניין:

   | פעיל | תמונה |
   |---|---|
   | כן | building-1.jpg |
   | כן | building-2.jpg |
   | כן | https://example.com/photo.jpg |

   - **תמונה**: שם קובץ מתוך התיקייה `assets/photos/` בריפו, או קישור מלא לתמונה באינטרנט.

### 4. פרסום כל לשונית כ-CSV
עשה את זה פעמיים, פעם לכל לשונית:
1. בתפריט: **קובץ ← שיתוף ← פרסום באינטרנט**.
2. בחלון שנפתח, בלשונית **קישור**:
   - ברשימה הראשונה (בהתחלה כתוב בה "כל המסמך") בחר את הלשונית: `הודעות` (ובפעם השנייה `תמונות`).
   - ברשימה השנייה (בהתחלה כתוב בה "דף אינטרנט") בחר **ערכים מופרדים בפסיקים (‎.csv)**.
3. לחץ **פרסום**, ואז **אישור**.
4. העתק את הקישור שמופיע. הוא מתחיל ב-`https://docs.google.com/spreadsheets/d/e/...` ומסתיים ב-`output=csv`.

### 5. הדבקת הקישורים ב-config.js
1. היכנס ל-https://github.com/israelb014/lobby-screen ולחץ על התיקייה `js` ואז על הקובץ `config.js`.
2. לחץ על סמל העיפרון (Edit this file) בצד ימין למעלה.
3. הדבק את הקישורים בין הגרשיים:
   ```js
   NOTICES_CSV_URL: 'https://docs.google.com/spreadsheets/d/e/....../pub?gid=0&single=true&output=csv',
   PHOTOS_CSV_URL: 'https://docs.google.com/spreadsheets/d/e/....../pub?gid=123456&single=true&output=csv',
   ```
4. לחץ על **Commit changes** (הכפתור הירוק), ושוב על **Commit changes** בחלון שנפתח.
5. תוך 5–10 דקות המסך יטען את עצמו מחדש ויתחיל לקרוא מהגיליון.

מעכשיו כל שינוי בגיליון מגיע למסך תוך כ-10 דקות (גוגל מעדכנת את הפרסום תוך כ-5 דקות, והמסך בודק כל 5 דקות). אין צורך לפרסם שוב.
אם הגיליון לא זמין, המסך מציג את מה שבקובץ `data/content.json`, ואם גם הוא לא זמין, את הנתונים האחרונים שנשמרו.

## החלפת התמונות, הכתובת, הברכה והלוגו

### תמונות הבניין
1. הכן תמונות לרוחב (מומלץ 1600 פיקסלים רוחב, JPG).
2. בריפו: היכנס לתיקייה `assets/photos`, לחץ **Add file ← Upload files**, גרור את התמונות ולחץ **Commit changes**.
3. כדי להציג אותן, יש שתי דרכים:
   - **עם הגיליון**: הוסף שורות בלשונית `תמונות` עם שם הקובץ, למשל `entrance.jpg`.
   - **בלי גיליון**: ערוך את `data/content.json` ושנה את הרשימה `"photos"`.
4. **החלפת תמונה קיימת באותו שם** (למשל `building-1.jpg`): העלה קובץ חדש באותו שם. כך היא מגיעה למסך: ב-04:00 בלילה, או מיד אם תריץ `./scripts/bump-version.sh` ותעשה push (או תשנה ידנית את המספר ב-`version.json` באתר GitHub).

### תמונת הנוף ותמונת הנרות
אלה הקבצים `assets/photos/beach.jpg` ו-`assets/photos/candles.jpg`. אפשר להעלות קבצים חדשים באותו שם, או לשנות את השמות ב-`js/config.js`:
```js
LANDSCAPE_PHOTO: 'beach.jpg',
CANDLES_PHOTO: 'candles.jpg',
```

### כתובת, ברכה ולוגו
ב-`js/config.js` (עריכה בעיפרון ← Commit changes):
```js
WELCOME_TEXT: 'ברוכים הבאים',
BUILDING_ADDRESS: 'רחוב הדוגמה 12, רמלה',
LOGO_IMAGE: '',           // למשל 'logo.png'
LOGO_TEXT: 'לוגו הבניין',
SHABBAT_BANNER: 'שבת שלום ומבורך',
```
- **לוגו**: העלה את קובץ הלוגו לתיקייה `assets/` (למשל `assets/logo.png`, עדיף PNG שקוף) וכתוב `LOGO_IMAGE: 'logo.png'`.
- ההודעה שמוצגת בשבת ובחג נמצאת ב-`SHABBAT_NOTICE` וב-`HOLIDAY_NOTICE`.
- שינוי ב-`config.js` מגיע למסך לבד תוך כ-5 דקות.

## עדכוני קוד

- המסך בודק כל 5 דקות (לא בשבת) את הקבצים `version.json` ו-`js/config.js`. אם אחד מהם השתנה, הוא נטען מחדש, כולל ה-Service Worker.
- אחרי כל שינוי בקוד (HTML, CSS או JS), הרץ:
  ```bash
  ./scripts/bump-version.sh
  git add -A && git commit -m "..." && git push
  ```
  הסקריפט כותב גרסה חדשה (תאריך ושעה) ל-`version.json`, והמסך יתעדכן תוך 5 דקות.
- ה-Action של החדשות לא נוגע ב-`version.json`.

## אמינות
- **Service Worker** (`sw.js`): שומר במטמון את כל קבצי האתר, הגופנים והתמונות. אם האינטרנט נופל, המסך ממשיך לעבוד עם הנתונים האחרונים.
- **טעינה מחדש** כל לילה ב-04:00 (לא בשבת), וגם אם יש יותר מ-20 שגיאות בשעה.
- כל חלק עטוף בטיפול שגיאות משלו. **תמונה שלא נטענת** מוחלפת במשטח כחול. על המסך לא מופיע טקסט שגיאה לעולם, ובמקרה הגרוע מוצג "—" במקום הערך.
